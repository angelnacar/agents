# 🔍 Deep Research para Obsidian

Sistema de investigación profunda con agentes de IA que genera informes en formato Obsidian.

## Características

- 🤖 Multi-agente especializado
- 🛡️ Guardarrailes de calidad
- 📝 Formato Markdown optimizado para Obsidian
- 📥 Descarga directa de informes

## Uso

1. Configura tu `OPENAI_API_KEY` en las variables de entorno del Space
2. Introduce una consulta de investigación
3. Espera a que los agentes generen el informe
4. Descarga el archivo `.md` y guárdalo en tu vault de Obsidian

## Requisitos

- OpenAI API Key válida
- Conexión a internet para búsquedas web
